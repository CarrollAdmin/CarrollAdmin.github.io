Upload your method source code, select RIOT/ESP32 benchmarks, generate applications, and run automated LinkLab compile/run evaluation.

source.zip requirements

  • The zip must contain `run.py` at the root, or inside one top-level folder. If you use another path, fill it in below.
  • The server runs: `python run.py --bench <bench_json> --output <app_dir>`.
  • `<bench_json>` is one selected RIOT/ESP32 IoTBench task.
  • `<app_dir>` must be a generated RIOT app directory containing `Makefile` and source files.
  • The generated `Makefile` must be at the app root, include `APPLICATION = <letters_digits_or_underscores>`, `BOARD ?= esp32-wroom-32`, `RIOTBASE ?= $(CURDIR)/../../..`, and `include $(RIOTBASE)/Makefile.include`; do not use `$(CURDIR)/../../...`, absolute `RIOTBASE` paths, or paths containing `Runtime/RIOT`.
  • Do not write outside `<app_dir>`; keep temporary files inside the uploaded source folder or output folder.
